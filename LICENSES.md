## Radix UI (MIT)

`src/runway/templates/progress.html` reproduces the `data-state`, `data-value` and
`data-max` attributes emitted by Radix UI's Progress primitive, version 1.1.11.
No Radix source code is included — only those attribute names, so that the
rendered markup matches the live page. The accompanying `role` and `aria-*`
attributes come from the W3C WAI-ARIA specification rather than from Radix, and
the CSS classes are this project's own.

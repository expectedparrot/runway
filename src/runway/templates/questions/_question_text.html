Without them -- every question that names no file, which is nearly all of them -- this is the single `.edsl-question-text` div it has always been, and the markup is unchanged. With them, the reference wraps the list in a bare div and each block in a bare div of its own, and the text blocks carry the same `.edsl-question-text` class the whole question used to. Class strings are inline here rather than passed in, for the same reason they are in every other question template: the stylesheet build scans templates, so a class named only in a .py file would have its rules dropped.

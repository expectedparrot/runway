{# Transcription of the reference implementation's radio control. The input is still the control -- focusable, in the tab order, announced, and what a click on the surrounding label reaches. It is only moved out of sight with `sr-only`, so what a respondent sees is the `-control` span drawn around it and the `-indicator` dot inside. Because the input is invisible it can no longer draw its own focus ring, which is why the control carries `has-[:focus-visible]` utilities. The reference emits this from one shared component used by every question that asks for a radio, so it is one include here for the same reason: the four choice types, the matrix grid and the stacked matrix would otherwise each hold their own copy of a string none of them owns. `data-checked`/`data-unchecked` are how the live page publishes which option is chosen, and what an author's CSS styles against. A preview is always unanswered, so every control here is `data-unchecked` -- and a click cannot change that, since nothing re-renders. Restoring the dot for a clicked radio is `base.css`'s job, the same as the stacked matrix's selected row. Class strings are inline rather than passed in, so this file can be diffed against the reference component side by side; a class string in a .py file is invisible to the stylesheet build, which scans templates and would drop the rules for it. The empty-comment separator lines exist only to suppress whitespace between literal elements; JSX discards that whitespace, so emitting it would break byte parity. See README. Callers pass `control_class` -- the size and cursor, which is the only part of the control the reference lets a call site decide -- and whichever of `input_id`, `input_name` and `input_value` that call site sets. React moves `value` after `className` on a controlled input, which is why the attribute order below is not the order the props are written in. #} {% set input_id = input_id | default(none) %} {% set input_name = input_name | default(none) %} {% set input_value = input_value | default(none) %} {#- -#} {#- -#} {#- -#} {#- -#}

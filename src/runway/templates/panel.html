{# One question's survey page inside a bundle. `display: contents` when active, so the panel disappears from layout and its child becomes a direct child of #root -- the survey shell is a chain of full-height flex containers, and an ordinary wrapper div would break it. The first panel carries `is-active` from the server, so a document opened without JavaScript still shows a question rather than nothing. `data-question-index` and `data-scenario-indices` appear only in a bundle bound to more than one scenario. Without them the panels are one per question and their order says everything, which is what the page script falls back to -- so an ordinary bundle carries the markup it always has. `data-exclusive` is on every checkbox panel, the empty list included: its absence means "not a checkbox", not "nothing is exclusive". The page script reads it from here rather than from a page-level table because piped options resolve per scenario, so one question can be several option lists with the exclusive one in a different place in each. #}
